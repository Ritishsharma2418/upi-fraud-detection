Why

What this project does

UPI fraud detection using supervised machine learning, as set out in the synopsis. The app creates a labelled dataset of UPI transactions, trains a logistic regression classifier, evaluates it with accuracy, precision, recall and F1-score, and then uses it to score payments in real time.

Fraud types covered

Fake collect requests, phishing and compromised devices, SIM-swap attacks, social engineering (new payee, unusual amount, night-time payments) and credential guessing (repeated wrong PIN).

Method

Ten features per payment: amount, night-time, new payee, new device, collect request, payments in last hour, wrong PIN attempts, account age, recent SIM change and location mismatch. Features are standardised, and fraud cases get a higher weight during training because fraud is rare (class imbalance). Data is split 80/20 into train and test.

Honest note

Real UPI transaction data is confidential, so the data here is synthetic, built from the fraud patterns in the literature review. The pipeline is the same one you would run on a real dataset such as those listed in the references.

Future scope

LSTM sequence models, streaming platforms, federated learning across banks, behavioural biometrics and device fingerprinting.
